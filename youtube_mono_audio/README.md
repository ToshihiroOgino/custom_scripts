# YouTube Mono Audio

YouTube の動画をボタンでモノラル再生に切り替える Tampermonkey 用のユーザースクリプト。

- 再生画面下部の `MONO` / `ST` ボタンで切り替える
- 初期状態はステレオで、動画が変わるとステレオに戻る
- Shorts は対象外

## インストール

[Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)のダッシュボードで下記のURLからスクリプトをインストールできる。

スクリプトURL: `https://raw.githubusercontent.com/ToshihiroOgino/custom_scripts/main/youtube_mono_audio/youtube-mono-audio.user.js`
